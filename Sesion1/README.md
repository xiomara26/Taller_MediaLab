# Taller de Python · Sesión 01: Mi repositorio de investigación

Kit de partida del Media Lab (PUCP). Sigue los pasos en orden.

## Archivos
- `datos_iniciales.py`: ejemplo guiado de listas y diccionarios. **Edítalo con los datos de tu caso.**
- `ejemplos_especialidades.py`: un diccionario por especialidad (periodismo, publicidad, audiovisual, desarrollo).
- `README.md`: este archivo. En tu repositorio, reemplázalo por **tu propio README** (plantilla al final).

## Pasos
1. En GitHub, crea tu repositorio (nombre sin espacios ni tildes) con un README inicial.
2. Crea la rama `datos-iniciales`.
3. En esa rama usa **Add file → Upload files** y sube `datos_iniciales.py` y `ejemplos_especialidades.py`.
4. Abre `datos_iniciales.py`, reemplaza los datos de ejemplo por entre 3 y 5 datos reales de tu caso, ejecútalo en VS Code o Colab y haz un commit con un mensaje claro.
5. Completa tu README con la plantilla de abajo.
6. Abre un Pull Request y fusiónalo con `main` (**Merge pull request**).
7. Copia el enlace de tu repositorio y compártelo en el chat.

## Cómo pedirle ayuda a Claude (prompt con cuatro ingredientes)
Contexto + tarea + material y formato + verificación. Ejemplo:

> Soy estudiante de [tu especialidad] y armo un repositorio con [tu caso]. Crea en Python una lista de diccionarios con [tus claves]. Usa estos datos: [tus datos]. Explica cada línea en una frase y dime cómo verificar que funciona.

Antes de ejecutar, **lee el código y anticipa qué hará**. Si no entiendes una línea, pídele que la explique. No pegues datos personales ni de fuentes reservadas.
